**Steam Bridge** даёт играть с друзьями по сети без проброса портов, белого IP и VPN.
Мод встраивается в сетевой слой Minecraft и пускает трафик через **Steam Datagram Relay (SDR)**. Пинг остаётся минимальным, а NAT почти любой сложности пробивается без проблем.

## Почему Spacewar (AppID 480)?
Мод передаёт данные через собственный API Steam (ISteamNetworkingSockets), а для этого Steam требует, чтобы оба игрока находились в одной "игре".

Именно поэтому по умолчанию используется **AppID 480 (Spacewar)**: это старая внутренняя тестовая игра Valve, которую сообщество уже давно приспособило под сетевые эксперименты, кооп и запуск пираток. Valve на это годами закрывает глаза, так что это самый безопасный вариант, если не хочется тратить лицензию реальной игры только ради связи двух игроков.

- **Важно:** AppID зашит в код на Spacewar, менять его через конфиг нельзя, и это сделано намеренно. Подстановка AppID реальной игры (особенно с VAC или EAC) может закончиться баном аккаунта, так что искать обходной путь не стоит.

## Настройка
- **Порт 25565:** при хостинге через Steam Bridge убедитесь, что порт свободен от других процессов. Если параллельно нужен обычный LAN-сервер Minecraft, просто укажите другой виртуальный порт в конфиге мода.
- **allowWithoutAuth:** отвечает за проверку Steam Session Ticket. Отключение немного повышает безопасность, но может вызывать проблемы с подключением при строгом/симметричном NAT.
- **interceptUdp:** ставит JVM-wide `DatagramSocket`-фабрику, чтобы голосовые моды (Simple Voice Chat, Plasmo Voice и т.п.) шли через Steam рядом с игровым трафиком. Работает только при запуске; в runtime переключить нельзя.

## Среда разработки
Версии, использованные при сборке и тестировании:
- **Java:** 8u492 (Eclipse Adoptium / Temurin, build 25.492-b09)
- **Minecraft Forge:** 1.12.2 - 14.23.5.2860
- **Gradle:** 4.10.3
- **ОС:** Windows 11 (amd64), на десятке тоже должно собираться без проблем

## Платформы и оптимизация
Ради компактности сборки (около 775 КБ), релизный .jar содержит нативные библиотеки только для **Windows x64**. После того как эта версия пройдёт обкатку, в планах добавить поддержку Linux.

> **Linux / macOS**
> Чтобы собрать под Linux или macOS, откройте `build.gradle` и уберите `exclude`-правила для `linux`/`darwin` и файлов `.so`/`.dylib`, после чего пересоберите проект. Возможно, придётся раскомментировать пару пакетов и слегка подправить код, чтобы всё завелось на вашей ОС.
