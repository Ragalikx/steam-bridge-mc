# Голос через Steam Bridge

SBM переносит UDP выбранного голосового мода через отдельное Steam P2P соединение. Аудио, кодеки, секреты, аутентификация голосового протокола, UI и позиционирование остаются у Simple Voice Chat или Plasmo. Голосовой мод устанавливается на обеих сторонах отдельно; его implementation и ресурсы не включены в SBM.

Включение: `interceptUdp: true` в `config/steambridge.json`. Forge 1.7.10 и 1.8.9 сохраняют отсутствие голосового туннеля. На остальных вариантах интеграция действует при наличии совместимого voice-мода. Присутствие API-классов проверяется перед регистрацией Plasmo addon.

## Simple Voice Chat

Адаптер написан для опубликованного `voicechat-api:2.5.0`. При `ClientVoicechatInitializationEvent` Steam-сессия получает явный клиентский сокет. Обычный IP-коннект и socket implementation другого плагина сохраняются. `VoicechatServerStartingEvent` предоставляет серверный сокет, регистрирующий фактический порт после `bind`, включая `bind(0)`, и адрес привязки. Wildcard `*` учитывается. Закрытие снимает только регистрацию этого экземпляра сервера. Позднее закрытие старого экземпляра не удаляет новый адрес, даже при повторном использовании того же порта.

Для старого Simple Voice Chat без клиентского socket API сохраняется фильтр JVM datagram factory. Он включается только при наличии соответствующего мода и не заменяет уже установленную factory. Такой fallback остаётся отдельным модпак-сценарием: это глобальный механизм JVM. Совместимость с произвольным старым релизом не заявляется.

## Plasmo Voice

Адаптер использует API 2.1.17. `UdpClientConnectEvent` подменяет стандартный `su.plo.voice.client.socket.NettyUdpClient` обёрткой. Её локальный UDP relay направляет байты в Steam, сохраняя delegate для кодирования и обработки протокола. Socket implementation другого аддона не оборачивается. Обычные внешние voice endpoints сохраняются.

`UdpClientClosedEvent`, ошибка подключения и закрытие игровой попытки освобождают relay. События `UdpServerStartedEvent` и `UdpServerStoppedEvent` учитывают identity сервера, чтобы остановка старого экземпляра не снимала адрес нового. Прежние Plasmo mixins удалены; API, Kotlin и ASM не включены в пользовательский JAR.

Обе скомпилированные реализации SBM, Java 8/JNA и Java 25/Panama, проверены по 13 закреплённым JAR. Minecraft и Steam при этой проверке не запускаются.

| Голосовой мод | Проверенные файлы для NeoForge 26.x |
| --- | --- |
| Plasmo Voice 2.1.17 | 26.1, 26.2, 26.3 |
| Plasmo Voice 2.2.0-beta.2 | 26.1, 26.2, 26.3 |
| Simple Voice Chat 2.6.25 | +26.1.2, +26.2, +26.3 |

SVC-файл +26.1.2 объявляет диапазон Minecraft [26.1,26.2), но это не заменяет проверку конкретного установленного патча. Также проверены четыре прежних JAR Plasmo 2.1.17: Fabric 1.16.5/1.20.1, Forge 1.19.2, NeoForge 1.21.1.

Проверяются внешние классы, дескрипторы методов и полей, public/static access, annotations и реализации абстрактных методов API-интерфейсов. Plasmo: 26 обращений к методам для Java 8, 27 для Java 25 из-за другого байткода вызова Object.getClass, два поля и девять обязательных реализаций. Simple Voice Chat: шесть обращений и 15 обязательных реализаций. Изменять голосовые адаптеры для этих API не потребовалось.

URL и SHA-256: `tools/voice-targets.json`. Повторение: `python tools/verify_voice.py --download` и `python tools/verify_voice.py --panama --download`. Отчёты: `build/voice-target-results.json`, `build/voice-panama-target-results.json`. ASM 9.11.1 используется только проверяющим инструментом и не включается в SBM.

Совместимость вызовов API подтверждена для этих файлов. Применение событий загрузчиком, настоящий голос через Steam, модпаки и будущие версии остаются отдельными проверками.

## Жизненный цикл и адреса

- Хост допускает voice handle только для принятого и разрешённого игрового Steam peer. Это проверка игровой Steam-сессии, ещё не доказательство завершённого Minecraft login; авторизация голосового протокола остаётся у voice-мода.
- Один игровой peer может занимать одно голосовое соединение. Общего лимита в четыре игрока в этом механизме нет. Автотест проверяет восемь допущенных peer; реальную ёмкость Steam/модпака надо измерять.
- Kick, закрытие мира и переподключение отзывают voice с учётом identity игровой сессии. Старый owner не закрывает и не использует её замену.
- Хостовый relay использует фактический адрес voice-сервиса. Wildcard IPv4/IPv6 переводится в loopback той же семьи; конкретный bind address сохраняется. Ответ принимается только с ожидаемого адреса и порта. Автотесты передают настоящие UDP-пакеты по `127.0.0.1` и `::1`.
- На клиенте Steam-перенаправление применяется к loopback voice endpoint, полученному через игровое подключение. Объявленный внешний voice host остаётся внешним UDP endpoint и может требовать обычного сетевого доступа.
- Если API не сообщает серверный порт, сохраняется прежний fallback: порт игры, затем 24454. При нестандартной конфигурации нужен реальный тест обоих логов.
- Адрес API voice-сервиса сохраняется при остановке Steam-host, пока сам voice-сервис продолжает работать. Его собственное закрытие снимает регистрацию; legacy socket не может перезаписать API-регистрацию.
- Один клиентский voice socket занимает туннель. Одновременная работа Simple Voice Chat и Plasmo через этот туннель не поддерживается.

## Источники и лицензии

Исследованные версии закреплены в `tools/voice-upstream.json`; релизные fixtures и исходные API JAR имеют SHA-256 в `tools/voice-targets.json` и `tools/locked-dependencies.json`.

У [Plasmo 2.1.17](https://github.com/plasmoapp/plasmo-voice/blob/4c717b85c4bbfa286c7809a4018137142798986b/LICENSE) указана LGPL-3.0. Файл [Simple Voice Chat исследованной ревизии](https://github.com/henkelmax/simple-voice-chat/blob/c5b7d9bba087d6c5f4aaf62394d2a06c50ee8fb7/license) содержит `All Rights Reserved`; публичный репозиторий сам по себе не означает MIT. В SBM написаны собственные адаптеры опубликованных API. Исходный голосовой код не копируется и не перераспределяется внутри мода.

## Итоговая игровая проверка

Проверить каждый voice-мод отдельно: Steam direct/Relay, переменные размеры пакетов, custom port, wildcard/конкретный bind, IPv6 bind, reconnect, kick, закрытие мира, остановку Steam и обычный IP-коннект после Steam. Проверить отсутствие voice-мода и конкурирующий addon socket. Сохранять логи обеих сторон. Обмен голосом и применение addon events в Minecraft ещё не подтверждены автоматическими тестами.
