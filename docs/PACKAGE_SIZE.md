# Размер пакетов

28 октября 2026 исключён `NamedField.class` из Forge 1.7.10, 1.8.9, 1.12.2 и NeoForge 26.x. Эти адаптеры не используют GUI-helper. В остальных сборках он нужен для reflection-привязок и сохраняется. Общий исходник и тесты остаются в проекте.

Проверка готового JAR запрещает его повторное включение в эти четыре пакета и ищет оставшиеся ссылки в class-файлах. Если адаптер начнёт использовать helper, сборка остановится: правило упаковки придётся пересмотреть.

Нативные библиотеки, callbacks, reflection aliases, локализации, лицензии и отладочные номера строк сохранены. Режим упаковки и степень ZIP-сжатия не менялись. Обфускация и упаковщики исполняемых библиотек не применяются.

## Linux bootstrap

`com/sun/jna/linux-x86-64/libjnidispatch.so` нужен JNA на Linux. Runtime-аддоны Java 8/17/21 предоставляют `libsteam_api.so` и `libsteamworks4j.so`, но не заменяют bootstrap JNA. Поэтому он остаётся рядом с соответствующими Java-классами JNA в основном пакете. Его прежнее обозначение как возможного мусора было неточным.

Перенос потребовал бы поддержки разных версий JNA и гарантированного порядка загрузки на каждом загрузчике. Этот проход не меняет загрузку библиотек ради уменьшения основного файла. Сам перенос также не уменьшил бы общий размер установки Linux.

JNA использует некоторые классы из JNI и reflection: отсутствие прямого Java-вызова в SBM не доказывает ненужность класса библиотеки. Для NeoForge 26.x JNA и JNI bridge уже исключены, используется Panama.

## Проверка

Все основные пакеты пересобираются штатным сборщиком. Сравнение с предыдущими JAR требует, чтобы каждый сохранённый файл имел прежнее содержимое, а единственным удалённым файлом в четырёх пакетах был `NamedField.class`. Runtime-аддоны должны оставаться побайтно идентичными. Сводка: `build/20261028-size-cleanup/results.json`.

Большого безопасного резерва в текущих архивах не обнаружено. Сокращение используемого транспорта или voice-интеграций ради размера меняло бы функциональность; изменение организации внутренних адаптеров потребовало бы отдельной разработки и проверки.
